## 📚 학습 정리

### 1. study_plan.md 정리 — 사촌 관계 발견 후 순서 재배치

원래 다음 큐 1순위는 Spearman 이었으나, 사촌 관계 한 줄 발견 후 순서 뒤집음:

```
cosine(X, Y)                        — 그냥 두 벡터의 각도
Pearson(X, Y)   = cosine(X − x̄, Y − ȳ)        ← 중심화 한 번
Spearman(X, Y)  = Pearson(rank(X), rank(Y))    ← rank 한 번
                = cosine(rank(X) − mean, rank(Y) − mean)
```

→ **세 형제가 일직선으로 정렬됨**. 본진은 다 cosine, 변환 한 단계씩만 추가. 그래서 Pearson 잡으면 Spearman 은 거의 보너스.

→ study_plan.md 에 "원래 Spearman 먼저였으나 가족 본진인 Pearson 부터" 라는 메모와 함께 순서 정정. cosine 은 ✅ 완료 섹션으로 이동.

### 2. Pearson 이 측정하는 것

| r 값 | 의미 |
|---|---|
| +1 | 완벽한 양의 직선 관계 |
| 0 | 직선 관계 없음 |
| -1 | 완벽한 음의 직선 관계 |

핵심 단어: **"직선"**. 곡선 관계는 못 잡음 — 그건 Spearman 차례.

기호: r (소문자). 범위 -1 ~ 1. 어제 박은 cosine 범위 사전 감각 그대로.

정식 명칭: Pearson product-moment correlation coefficient. 1895년경 Karl Pearson 정리. 통계학의 가장 오래된 기초 도구.

### 3. 식 부품 분해 — 새로운 건 단 하나

```
              Σ (xi - x̄)(yi - ȳ)
   r  =  ──────────────────────────────────
          √Σ(xi - x̄)²  ×  √Σ(yi - ȳ)²
```

| 기호 / 구조 | 본인 머리 상태 |
|---|---|
| Σ (다 더하기) | 어제까지 도배함 ✅ |
| √ (제곱근) | 어제까지 도배함 ✅ |
| 분자 = "곱하고 더하기" 구조 | **내적** 그 자체 ✅ |
| 분모 = "제곱해서 더하고 루트" | **노름** 그 자체 ✅ |
| **x̄ — 평균, (xi - x̄) — 편차** | ← 새로운 거 단 하나 |

→ "피어슨 식 이해하기" 라는 과제는 사실 **"중심화 (mean-centering) 가 뭘 하는지 이해하기"** 라는 한 줄 과제로 축약됨.

### 4. 손계산으로 중심화의 진짜 의미 박기

```
X = [1, 2, 3, 4, 5]      ← 1씩 오름
Y = [10, 8, 6, 4, 2]     ← 2씩 내림
```

직관: *"완벽한 음의 직선 관계. Pearson = -1 나와야지."*

#### 그냥 cosine 으로 돌리면

```
X · Y   = 70
‖X‖    ≈ 7.42
‖Y‖    ≈ 14.83
cosine = 70 / (7.42 × 14.83) ≈ +0.636
```

→ **+0.636.** 직관과 정반대.

**왜?** 두 벡터 모두 값이 다 양수. 좌표 평면에서 둘 다 1사분면 가리킴. cosine 은 "전반적 방향" 만 보니까 +값. **변동 패턴은 못 봄.**

#### 평균 빼고 (중심화하고) 돌리면

```
x̄ = 3,  ȳ = 6
X − x̄ = [-2, -1,  0,  1,  2]
Y − ȳ = [ 4,  2,  0, -2, -4]    ← 평균 빼니 음수 등장
```

```
분자 = (-2)(4) + (-1)(2) + 0 + (1)(-2) + (2)(-4) = -20
분모 = √10 × √40 = √10 × 2√10 = 20
r = -20 / 20 = -1.0  ✅
```

**정확히 -1.** 직관과 일치.

#### 한 줄 메타

> **중심화 = "절대 수준" 을 지우고 "변동 패턴" 만 남김.**

```
원본 X = [1, 2, 3, 4, 5]        ← "평균 3 근처" + "1씩 변동"
중심화 = [-2, -1, 0, 1, 2]      ← 평균 정보 지우고, 변동만 남김
```

SQL 본진 언어로: `x - avg(x) over ()` 한 줄. 이 변환을 모든 row 에 적용한 뒤 cosine 돌리면 그게 Pearson.

| | cosine 이 보는 것 | Pearson 이 보는 것 |
|---|---|---|
| 관심 | 전체 방향 | **변동 패턴** |
| 답이 -1 일 조건 | 두 벡터 정반대 | 변동만 정반대면 OK (원본은 다 양수여도 됨) |
| 절대 수준 | 답에 영향 줌 | **무시함** |

### 5. 용어 정리 — 성분 / 편차 / 잔차 / 오차

#### 성분 (component)

벡터의 각 위치 값. `[gasoline, diesel, premium]` 에서 각 값 하나하나가 **벡터의 성분**.

- "원소" 도 틀리진 않지만 집합/배열에서 더 많이 씀
- "성분" 은 **벡터 전용 단어** 라 의미가 더 좁고 정확

#### 편차 vs 잔차 vs 오차 — 사촌 3종

| 단어 | 영어 | 식 | 누구 vs 누구 |
|---|---|---|---|
| **편차** | deviation | xi − x̄ | 관측값 vs **평균** |
| **잔차** | residual | yi − ŷi | 관측값 vs **예측값** (관측 가능) |
| **오차** | error | yi − f(xi) | 관측값 vs **진짜 함수** (이론. 관측 불가) |

→ 평균은 *"모델 없는 모델"* 의 예측. ŷ 는 *"피처 본 후의 예측"*. 진짜 함수 f(x) 는 자연의 진실이라 우리가 모름.

#### ML 본진과의 연결 — "예측값 = 평균" 이라는 기억의 정체

본인이 ML 에서 *"예측값 ŷ = 평균 ȳ"* 라고 몇 번 배웠던 기억의 출처:

```
일반 회귀:        ŷi = b0 + b1·xi + ...     ← 피처마다 다른 ŷ
                  잔차 = yi - ŷi

피처 없는 극단:   ŷi = ȳ  (모든 i 에서 평균으로 예측)
                  잔차 = yi - ȳ              ← 이 순간 편차 값과 동일
```

→ **null model (피처 없는 가장 단순한 모델)** 에서 잔차 = 편차 (숫자 같음).
→ R² 분해 (TSS = Σ(yi - ȳ)² / RSS = Σ(yi - ŷi)²) 에서 두 식 나란히 봤던 게 머리에 남은 것.
→ 그래도 단어는 구분: *"기준이 평균인지 모델 예측인지"* 가 의미 차이.

**한 줄**: *편차는 잔차의 특수 케이스 (null 모델일 때). 모든 잔차가 편차는 아님.*

→ ML 석사 본진 회귀 챕터에서 **잔차 제곱합 (RSS) vs 총 제곱합 (TSS)** 같은 단어 만났을 때 안 헷갈리게 됨. 표준 어휘 한 쌍 정리.

### 6. 식 순서 함정 — "Ai - Ā 순서 바뀌어도 되지?" 의 함정

본인 논리: *"어차피 제곱해서 같아지니까 순서 무관."*

→ **반은 맞고 반은 함정.**

#### 분모 — 본인 말 맞음

```
√Σ(Ai - Ā)²    vs    √Σ(Ā - Ai)²
```

제곱이라 부호 무관. **순서 무관** ✓

#### 분자 — 함정. **제곱이 아니라 곱셈**

```
Σ (Ai - Ā) × (Bi - B̄)
   └─────┘   └─────┘
   A의 편차   B의 편차    ← 서로 다른 두 값의 곱
```

A 만 뒤집어서 (Ā - Ai) 로 적으면:

```
원래
X − x̄ = [-2, -1, 0, 1, 2],  Y − ȳ = [4, 2, 0, -2, -4]
분자 = -20  →  r = -1.0 ✓

X 만 뒤집은 경우
x̄ − X = [2, 1, 0, -1, -2]
분자 = (2)(4)+(1)(2)+0+(-1)(-2)+(-2)(-4) = +20
r = +1.0 ✗  부호 통째로 뒤바뀜!
```

| 케이스 | 결과 |
|---|---|
| 둘 다 (값 − 평균) | OK ✓ |
| 둘 다 (평균 − 값) | OK ✓ (마이너스 둘이 곱해서 상쇄) |
| **한쪽만 뒤집기** | **부호 통째 뒤바뀜** ✗ |

**한 줄**: *분모는 제곱이라 안전, 분자는 곱셈이라 양쪽 일관성 필요.*

관행은 **(값 − 평균)** 으로 통일. 직관 (*"평균 위면 +, 평균 아래면 −"*) 과 부호가 맞아서.

### 7. DuckDB `CORR()` 적용 — 본인 주유소 데이터에 실전

가장 짧은 SQL:

```sql
with base as (
  select
    part_dt
    , max(case when prodcd = 'B027' then price end) as gasoline_prc
    , max(case when prodcd = 'D047' then price end) as diesel_prc
  from read_parquet('s3://petroleum-project/national_avg/price/*/*.parquet')
  group by 1
)
select corr(gasoline_prc, diesel_prc) as pearson_correlation
from base
```

→ 대부분 DBMS 가 `CORR()` 지원. 본인도 자주 쓰는 함수. 어제 self-join 으로 손코딩한 cosine 과 같은 패턴 — **빌트인 함수 존재 = 손코딩 안 해도 됨.** 어제 박은 *"잘 만들어진 빌트인은 표현 짧고 + 실행 빠름"* 의 재확인.

### 8. 연도별 분해 — Pearson 의 진짜 가치 발견

전체 기간 한 줄 r 보다, **연도별 r** 이 훨씬 재미있음:

| 시기 | 휘발유-경유 r | 무엇이 |
|---|---|---|
| 2020-2021 (코로나 한복판) | 0.998, 0.996 | 양쪽 수요 같이 폭락 → **동조 유지** |
| 2022 (전쟁 시작 2/24) | 0.708 | 디젤 비대칭 충격 시작 |
| **2023 (전쟁 한복판)** | **0.563** | 깨짐의 절정 |
| 2024 | 0.756 | 정상화 진행 |
| 2025-2026 | 0.958, 0.991 | 동조 회복 |

#### 시간선 교정 — "코로나가 깼다" 가 아니라 "전쟁이 깼다"

본인 초기 가설: *"코로나 때 동조 풀렸나?"*
→ 데이터: **코로나는 멀쩡, 전쟁이 깼다.**

- **코로나** = *"양쪽 다 같이 죽는"* **대칭 수요 충격** → 동조 유지
- **러-우 전쟁** = *"디젤에만 따로 작용하는"* **비대칭 공급 충격** → 동조 깨짐

#### Pearson 0.99 → 0.56 의 통계적 의미

- Pearson 높음 = *"공통 동력이 지배함"*. 휘발유/경유의 공통 동력 = **원유 가격**.
- Pearson 떨어짐 = *"공통 동력 위에, 한쪽에만 작용하는 다른 동력이 들어옴"*.
- → 질문 재정의: *"왜 동조가 깨졌지?"* → *"경유에만 따로 작용한 게 뭐였지?"*

#### 후보 가설

- **가장 큰 그림**: 러-우 전쟁의 디젤 비대칭 충격 (러시아 = EU 디젤 주공급원, 제재로 글로벌 디젤 가격 독립 폭등)
- **한국 특수**: 유류세 인하 정책의 비대칭 조정 (2022-07 ~), 화물연대 파업 (2022 말 ~ 2023)
- **수요 측**: 코로나 후 화물 (디젤) vs 승용 (휘발유) 회복 속도 차이

#### 검증 도구 — 롤링 corr

연도별 단일 r 로는 *"2023년 안에서 언제"* 가 안 보임. **30일/60일 롤링 corr** 로 일자별 시계열 그리면 급락 시점이 한눈에 보임.

급락 시점이 2022-02 부근이면 전쟁 가설, 2022-07 부근이면 유류세 가설, 2022-12 부근이면 파업 가설. **언제 깨졌는지가 어떤 가설인지 좁혀줌.**

(*0.56 을 본인이 "남남 같다" 고 표현했지만 정확히는 "중간 정도 양의 상관". 휘발유/경유 입장에선 충격적으로 낮은 거지, 절대 척도로 남남은 아님. 부동산 가격과 신발 사이즈 같은 게 진짜 남남.*)

```sql

  select
    part_dt
    , max(case when prodcd = 'B027' then price end) as gasoline_prc

from base
```

### A2. 연도별 Pearson — 진짜 재미있는 결과

```sql
with base as (
  select
    part_dt
    , max(case when prodcd = 'B027' then price end) as gasoline_prc
    , max(case when prodcd = 'D047' then price end) as diesel_prc
  from read_parquet('s3://petroleum-project/national_avg/price/*/*.parquet')
  group by 1

select
  substring(cast(part_dt as string), 1, 4) as yyyy

from base
group by 1
order by 1
```

## 💡 오늘의 큰 깨달음

1. **세 형제 일직선 정렬**: cosine → Pearson (중심화) → Spearman (rank). 본진은 다 cosine. 변환 한 단계씩 추가. 그래서 Pearson 잡으면 Spearman 거의 보너스.

2. **중심화 한 줄의 위력**: `x - avg(x) over ()` 한 줄로 절대 수준 지우고 변동 패턴만 남김. cosine 이 +0.636 답한 데이터에서 Pearson 이 -1.0 으로 *정반대* 답할 수 있는 게 이 한 줄 때문.

3. **편차/잔차/오차 사촌 3종**: 같은 모양 (관측값 − 무엇) 의 식인데 *"기준이 무엇이냐"* 가 다름. 평균/예측값/진짜함수. ML 에서 *"예측값 = 평균"* 으로 기억하는 건 null model 의 특수 케이스.

4. **식 부품 분해 = 본인 학습 결**: cosine 5일간 들여서 분자=내적, 분모=노름 라고 분해해서 본 게 오늘 Pearson 진입을 *"새로운 거 단 하나"* 로 줄여줌. 학습 나침반 (벡터 연산 4종) 의 복리.

5. **순서 함정 — 제곱이라고 다 안전한 게 아님**: 분모 (제곱) 와 분자 (곱셈) 가 다르게 작동. 식의 부품을 "제곱인지 곱셈인지" 구분해서 보는 눈이 *공식을 외우는 사람* vs *공식을 다루는 사람* 의 차이.

6. **상관계수는 답이 아니라 질문**: 0.56 자체는 무의미. *"왜 떨어졌지?"* 라는 후속 질문 유발이 가치. **단일 값보다 변화** 가 신호. 시계열로 쪼개야 보임. 면접 답안용으로도 *"r 값 외운다"* 와 *"r 변화를 신호로 썼다"* 는 차원이 다름.

7. **데이터가 본인 가설을 교정함**: *"코로나가 깼다"* 라는 직관 → 데이터 *"코로나는 멀쩡, 전쟁이 깼다"*. 대칭 수요 충격과 비대칭 공급 충격의 차이. **가설을 데이터로 검증하는 자체** 가 이 작업의 모양.

8. **빌트인 함수의 두 마리 토끼 재확인**: `CORR()` 는 거의 모든 DBMS 에 있음. 손코딩 가능하지만 빌트인이 표현도 짧고 빠름. 어제 cosine 의 `list_cosine_similarity` 교훈 재확인.
