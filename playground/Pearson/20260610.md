# 2026-06-10 작업 일지 — Spearman, 그리고 "그림도 거짓말한다"

> *Cosine → Pearson에 이어 Spearman으로. 핵심은 "순위로 바꾼 뒤 Pearson"이라는 한 줄이었지만, 진짜 수확은 그 뒤였다. 연도별로 쪼개 두 지표가 엇갈리는 해(2022·2023)를 신호로 잡고, 산점도를 그렸더니 교과서 구름이 아닌 '시계열 궤적'이 나왔다. "이 루프가 진짜 시간 경로냐, 우연이냐"를 의심하고 → 색 그라데이션으로 시간축을 되살려 직접 검증까지. 마지막엔 "plt 문법은 못 외우겠다"는 솔직한 고백에서, LLM 시대의 작업 분업(판단·해석은 나, 문법은 모델)을 본인 입으로 정리.*

---

## 🎯 오늘 한 일

1. **Spearman = 순위 변환 + Pearson** — `corr(rank(x), rank(y))` 라는 정체성 잡기
2. **사고실험 `y=x²`** — Pearson<1.0(직선 아님) vs Spearman=1.0(순서 동일)로 둘의 차이 체감
3. **Pearson 오해 교정** — "증가량이 커서"가 아니라 "직선이 아니라서" 깎인다 (Pearson은 스케일 불변)
4. **corr의 데이터 레이아웃** — "관측치=행, 비교대상=컬럼". 변수 vs 변수 / 아이템 vs 아이템 둘 다 가능 (축 선택의 문제)
5. **average rank(동점 평균) 직접 구현** — `row_number()` → `avg() over (partition by 값)`
6. **연도별 Spearman vs Pearson** — `partition by yyyy`로 순위 매기고 연도별 corr 비교
7. **두 지표 엇갈림 해석** — 3가지 패턴으로 정리
8. **산점도 → 시계열 궤적 발견**, 그리고 **산점도의 맹점(시간축 상실)** 인식
9. **가설 검증** — 색 그라데이션 + 선 잇기로 시간축을 복원, 히스테리시스 확증
10. **메타 결론** — LLM 시대의 시각화 학습관 / 작업 분업

## 📚 학습 정리

### 1. Spearman = 순위로 바꾼 뒤 Pearson

```
Pearson(value_x, value_y)              -- 원래 값으로 상관
Spearman = Pearson(RANK(x), RANK(y))   -- 순위로 바꾼 뒤 상관
```

- 새 공식 암기가 아니라 **Pearson 앞에 "순위 변환" 전처리 한 단계**가 붙은 것.
- 효과 ①: 비선형이어도 **방향이 일관(단조)**이면 잡아낸다. ② 이상치에 강함(100만도 그냥 꼴등 1개).

### 2. Pearson(선형) vs Spearman(단조)

```
Pearson이 보는 것  →  점들이 "직선" 위에 얼마나 잘 놓이나 (linearity)
Spearman이 보는 것 →  점들이 "한 방향"으로만 가나      (monotonicity)
```

- `y=x²`(x>0): 직선 아님(→Pearson 깎임) + 계속 오름(→Spearman 만점) → 둘이 갈라짐.

### 3. Pearson은 "스케일"에 무감각 — 깎이는 진짜 이유

- `y = 1000x` 처럼 증가폭이 압도적이어도 **완벽한 직선이면 Pearson = 1.0**.
- z-score(자기 표준편차로 나눔)를 쓰기 때문에 단위·증가폭은 싹 지워짐 (키를 cm로 재든 m로 재든 동일).
- 즉 `y=x²`가 깎이는 건 **증가량이 커서가 아니라 "꺾여 있어서(직선이 아니라서)"**.
- 한 몸 사실: 단순선형회귀에서 **`R² = Pearson²`**.

### 4. corr의 데이터 레이아웃 — 분석 설계의 핵심

```
corr는 항상 "행 = 관측치 N개, 컬럼 = 비교할 둘"을 먹는다.
  → 같은 행의 (A값, B값) 쌍을 N개 모아 둘이 함께 오르내리는지 본다.

분석 설계 = "무엇을 관측치(행)로, 무엇을 비교대상(컬럼)으로 둘까"
  · 휘발유 vs 경유 동조  →  관측치=날짜,  컬럼=휘발유/경유
  · A주유소 vs B주유소   →  관측치=날짜,  컬럼=A가격/B가격
```

- **"correlation은 변수용, cosine은 아이템용"은 가짜 이분법.** 같은 corr로 둘 다 됨 — 뭘 행에 세우느냐만 다름.
- (Pearson은 사실 "평균을 뺀 두 벡터의 cosine"이라, 유사도로 써도 정당.)
- 주유소끼리 비교하려면 공통 축(관측치)이 풍부해야 함 → 유종 3개로는 표본 부족, **날짜(시계열)**가 자연스러운 축.

### 5. average rank(동점 평균) — SQL 3형제에 없는 제4의 길

동점 `[10,20,20,30]` 처리:

```
ROW_NUMBER : 1, 2, 3, 4     (동점인데 억지 순서)
RANK       : 1, 2, 2, 4     (다음 건너뜀)
DENSE_RANK : 1, 2, 2, 3     (안 건너뜀)
average    : 1, 2.5, 2.5, 4 ← Spearman 정석
```

- 정의: **"동점이 차지하는 자리 번호들의 평균"**. 20들이 2·3번 자리 → (2+3)/2=2.5.
- **만드는 법 1(정의 그대로)**: `row_number()`로 자리(1,2,3,4) → `avg(rn) over (partition by 값)`로 같은 값끼리 평균.
- **만드는 법 2(트릭)**: `RANK() + (COUNT(*) OVER (PARTITION BY 값) - 1) / 2.0`.
- **검산 팁**: 자리 번호 합은 보존된다. `1+2+3+4=10`이면 평균순위 합도 10. 안 맞으면 틀린 것.
- 주의: 동점을 진짜 동점으로 남기려면 `order by`에 tie-breaker(`, uni_cd`)를 **넣지 말 것**.

### 6. 두 지표가 엇갈릴 때 — 3가지 패턴

```
Spearman > Pearson  →  한 방향으로 휘었다 (비선형 단조).      예: 2022 (0.81 > 0.71)
Spearman < Pearson  →  횡보/노이즈로 순위가 흔들렸다.         예: 2023 (0.42 < 0.56)
Spearman ≈ Pearson  →  깔끔한 직선.                          예: 나머지 대부분
```

- 단일 0.99는 밋밋. **두 지표가 엇갈리는 해가 "여기 뭔 일 있었다"는 신호등.**
- (※ 2023 "횡보" 가설은 산점도 보고 수정됨 → 아래 8번)

### 7. 산점도는 "구름"이 아니라 "궤적"이 나온다 (시계열이라서)

- 독립 관측치 → 구름처럼 흩어짐. **시계열 → 인접 날짜가 가까워 선처럼 이어진 궤적**(자기상관).
- "리얼데이터라서"가 아니라 **"시계열이라서"** 이렇게 나옴.
- **루프(고리) = 히스테리시스**: 올라간 길과 내려온 길이 다름 → 한 x에 y가 여럿 → 직선 불가(Pearson↓) + 순서 엉킴(Spearman↓).

### 8. 산점도도 "시간"을 버린다 — 그래서 검증이 필요했다

- 핵심 의심(유저): *"점에 날짜 라벨이 없는데, 1월 점과 12월 점이 우연히 겹쳤을 수도 있잖아?"* → **정확한 지적.**
- corr도 산점도도 **둘 다 시간 순서를 안 보여줌.** "히스테리시스"는 그림이 증명한 게 아니라 인접성 가정에 기댄 **가설**이었음.
- **검증법(유저 아이디어)**: 점을 날짜순 정렬 → **색 그라데이션**(연초=보라→연말=노랑)으로 시간축을 되살림 + **선으로 시간순 잇기**.
  - 색이 매끄럽게 한 바퀴 돌면 → 진짜 시간 경로(히스테리시스 입증)
  - 색이 뒤죽박죽이면 → 우연(반증)
- **결과: 색이 매끄럽게 흘러 → 히스테리시스 확증.** 2022는 상반기 급등(아래 경로)·하반기 하락(위 경로)로 올라간 길≠내려온 길.

### 9. 시각화 = "문법"이 아니라 "어휘 + 해석"

```
✕ 안 외워도 됨  : plt 함수명·파라미터·색코드  → 클로드가 생성
○ 외울 가치 있음 : 어떤 그래프가 무엇을 드러내나 → 클로드에 줄 '지시의 언어'
○ 길러야 함     : 나온 그림이 맞는지 읽고 검증하는 눈
```

- 시각화 어휘 예: 관계의 모양→산점도 / 시간추세→라인 / 분포·이상치→히스토그램·박스플롯 / 상관 한눈에→히트맵.
- "그래프 뽑아"와 "히스테리시스가 드러나게 연도별 산점도 격자로"의 결과물은 천지차. **지시의 정밀함이 곧 실력.**

## 🎁 오늘 코드 (핵심)

### A. 연도별 Spearman vs Pearson (SQL)

```sql
with step1 as (
  select substring(cast(part_dt as varchar),1,4) as yyyy, part_dt
       , max(case when prodcd='B027' then price end) as gasoline_prc
       , max(case when prodcd='D047' then price end) as diesel_prc
  from read_parquet('s3://petroleum-project/national_avg/price/*/*.parquet')
  group by 1,2
)
, rnk as (
  select yyyy, part_dt, gasoline_prc, diesel_prc
       , row_number() over (partition by yyyy order by gasoline_prc desc) as gasoline_rnk
       , row_number() over (partition by yyyy order by diesel_prc   desc) as diesel_rnk
  from step1
)
, avg_rnk as (
  select *
       , avg(gasoline_rnk) over (partition by yyyy, gasoline_prc) as gasoline_avg_rnk
       , avg(diesel_rnk)   over (partition by yyyy, diesel_prc)   as diesel_avg_rnk
  from rnk
)
select yyyy
     , corr(gasoline_avg_rnk, diesel_avg_rnk) as spearman
     , corr(gasoline_prc,     diesel_prc)     as pearson
from avg_rnk
group by 1 order by 1;
```

### B. 시간축을 색으로 되살린 검증 (Python) — 2년 여정

```python
sub = df[df['yyyy'].isin(['2022','2023'])].sort_values('part_dt').reset_index(drop=True)

fig, ax = plt.subplots(figsize=(11, 8))
ax.plot(sub['gasoline_prc'], sub['diesel_prc'], color='gray', alpha=0.3, linewidth=0.8, zorder=1)
sc = ax.scatter(sub['gasoline_prc'], sub['diesel_prc'], c=range(len(sub)), cmap='viridis', s=22, zorder=2)
fig.colorbar(sc, ax=ax, label='경과 일수 (2022.1 → 2023.12)')
plt.show()
```

- 새로 익힌 시각화 도구: `subplots(행,열)`+`axes.flatten()`+`for/zip`(반복 그림), `c=range(len)`+`cmap`+`colorbar`(시간을 색으로), `.iloc[0]`/`.iloc[-1]`(출발·도착점).

## 💡 오늘의 큰 깨달음

1. **숫자는 거짓말한다 — 그려봐야 안다.** corr 0.56만 보면 "그냥 약한 상관"이지만, 산점도는 루프·곡선·횡보를 드러냄. (앤스컴의 콰르텟: 상관계수 같아도 모양은 딴판.)

2. **그림도 거짓말한다 — 시간축을 검증하라.** 산점도는 시간을 버린 그림. "루프=히스테리시스"는 가설일 뿐, 색 그라데이션으로 시간을 되살려야 입증된다. 의심 → 도구 제작 → 확인의 과학적 루프를 직접 돌린 날.

3. **두 지표의 "차이"가 진단 도구.** S>P/S<P/S≈P 3패턴으로 "어떻게" 관계가 깨졌는지까지 읽힌다. 단일 숫자보다 두 렌즈의 격차가 정보.

4. **분석 설계 = 행/열 선택.** corr은 "관측치=행, 비교대상=컬럼". 변수든 아이템이든 뭘 행에 세우느냐가 전부. 함수가 아니라 데이터 모양의 문제.

5. **LLM 시대의 분업 — 판단·해석은 나, 문법은 모델.** `plt` 문법 암기는 가성비 0. 가치는 (1) 무엇을 왜 그릴지, (2) 나온 걸 읽고 의심하고 검증하는 눈. 오늘 plt 한 줄 안 외우고도 분석을 완성한 것이 그 증거. 핀다 query-helper에서 증명한 "조립자" 정체성 그대로.
