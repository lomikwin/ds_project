★ = 해당 유종의 최고 상관계수 지점
· lag = 국내 휘발유가를 며칠 전 국제유가와 짝지었는지 (lag 0 = 같은 날)
· Dubai 추이 막대는 Dubai 최소값(0.90576)~최대값(0.92058) 구간을 100%로 정규화한 것입니다. 실제 변동폭은 0.015에 불과하므로 막대는 차이를 크게 과장해 보여줍니다. 모양(고원의 위치)만 참고하세요.
· 표본 수가 lag 전 구간에서 3행 이내로 일정합니다(Dubai 4,579~4,582 / Brent 4,713~4,716 / WTI 4,599~4,601). lag끼리 상관계수를 비교하는 것이 타당하다는 근거입니다.
· 국제유가는 거래일만 존재하므로(휴장일 행 없음), 주말·공휴일 약 2,100일은 매칭되지 않아 계산에서 제외되었습니다.

이 표를 읽을 때 주의할 점
두 시계열 모두 18년간 강하게 상승했습니다. 그래서 상관계수 0.9의 대부분은 "둘 다 함께 올랐다"는 공통 추세가 만든 값이며, 시차에 따른 차이는 0.015 구간에서만 움직입니다. 즉 최고점의 위치(약 2~3주)는 신뢰할 만하지만, 0.92라는 값 자체를 "관계의 강도"로 읽으면 과대평가입니다. 변화량(차분) 기준으로 다시 계산해 검증할 예정입니다.

사용 쿼리 (DuckDB)

with lag_n as (
    select generate_series as lag_n from generate_series(0, 30)
)
, gasoline_price as (
    select
      cast(strptime(cast(t1.part_dt as varchar), '%Y%m%d') as date) as part_dt
    , t2.lag_n
    , cast(strptime(cast(t1.part_dt as varchar), '%Y%m%d') as date)
        - cast(t2.lag_n as int) as lag_dt
    , t1.price
    from read_parquet('s3://.../national_avg/price/*/*.parquet') t1
    cross join lag_n t2                      -- 날짜 1개 → lag 31개 행으로 복제
    where t1.part_dt >= '20080415'
      and t1.part_dt <= '20260731'
      and t1.PRODCD  =  'B027'               -- 휘발유
)
, crude_oil_price_join as (
    select t1.part_dt, t1.lag_n, t1.price, t2.Dubai, t2.Brent, t2.WTI
    from gasoline_price t1
    left join read_parquet('s3://.../crude_oil_price/*/*.parquet') t2
      on  t1.lag_dt   =  t2.part_dt
      and t2.part_dt  >= '2008-03-01'        -- 국내가 시작일보다 앞서 열어둠
      and t2.currency =  'USD'
)
select
  lag_n
, count(distinct case when Dubai is not null then part_dt end) as n_dubai
, corr(price, Dubai) as corr_dubai
, corr(price, Brent) as corr_brent
, corr(price, WTI)   as corr_wti
from crude_oil_price_join
group by 1
order by 1;

lag를 컬럼(가로)이 아니라 행(세로)으로 만든 것이 핵심입니다. generate_series로 lag 축을 만들고 CROSS JOIN으로 날짜를 복제하면, lag를 31개에서 91개로 늘려도 쿼리는 숫자 하나만 바뀝니다.
