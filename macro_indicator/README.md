# macro_indicator

> 국내 유가를 움직이는 **외생 동인(거시·국제 지표)** 수집 도메인.
> 첫 임무는 유가 예측 모델의 **upstream 레이어**지만, 환율·거시지표는 그 자체로
> 다른 분석에도 두루 재사용할 범용 자산으로 본다.

---

## 1. 이 도메인의 정체

석유 밸류체인 메타포로 보면:

```
[macro_indicator]  ← 국제 원유·환율·거시 (上流, upstream)
        │  국제유가 → 국내 반영 (lag 약 2~3주)
        ▼
[national_avg] · [station_price]  ← 국내 유가 (下流, downstream)
```

- `national_avg` / `station_price` (국내 소매 유가) = **하류**, 즉 예측 대상(y).
- `macro_indicator` (이 폴더) = **상류**, 즉 예측 입력(x = 외생 동인).
- 이름을 `macro_indicator`로 둔 이유: "유가의 상류"라는 관계에 묶이지 않고,
  데이터의 *정체*(거시지표)만 가리켜 **유가 밖 용도로도 재사용**하기 위함.

## 2. 최우선 수집 대상 — 4종

| 데이터 | 의미 | 비고 |
|---|---|---|
| WTI (텍사스산) 일별 | 미국 벤치마크 원유 | |
| Brent (북해산) 일별 | 유럽 벤치마크 원유 | |

> 원칙: **최대한 과거(장기 히스토리) 포함**해서 백필.

## 3. 소스 결정 (검토 완료 · 2026-06-15 재조정)

핵심 결론: **원유 3종은 오피넷 한 곳(CSV+크롤링)으로 전부 덮인다 — 두바이 포함.**
오피넷 국제유가 화면이 Dubai·Brent·WTI를 **일별, 2008년~, CSV**로 제공함을 확인.
이로써 두바이 일별 확보 문제가 한 방에 해결되고, ECOS는 환율 전용으로 단순해짐.

### 우선순위 요약

| 순위 | 소스 | 무엇 | 방식 | 역할 |
|---|---|---|---|---|
| 1 | **OPINET 원유** | Dubai·Brent·WTI | CSV 백필 + 일별 크롤링 | **코어** |
| 2 | **ECOS** | 환율(주요국) | 공식 API | 코어 |
| 3 | **FRED** | WTI·Brent | 공식 API | 교차검증·폴백 |
| 4 | **OPINET 석유제품** | 싱가포르 MOPS | 같은 크롤러 확장 | 보조 |

### 1️⃣ OPINET 원유 3종 — 코어 (먼저 구축)
- 위치: 유가관련정보 > 국제유가 > **원유** (`glopcoilSelect.do`)
- 내용: **Dubai / Brent / WTI**, 일별 $/Bbl, **2008-01-02 ~ 현재**.
- 공식 API 없음(무료 API 22종은 전부 국내) → **화면 CSV + 크롤링**으로 수집.
  1. **백필**: 화면 **CSV저장**으로 2008~현재 전체 한 번에 다운로드.
  2. **일별 증분**: `조회`/`CSV저장`이 호출하는 **숨은 `.do` 엔드포인트**(날짜 파라미터)를
     F12 → Network 탭에서 캡처 → 매일 어제 날짜로 1회 호출.
- 트래픽 하루 ~1콜 → IP 차단 위험 사실상 없음.
- 💡 **이 크롤러가 곧 §4 석유제품 크롤러의 프로토타입.** `glopcoilSelect.do`(원유)와
  `glopopdSelect.do`(석유제품)는 **형제 엔드포인트** — 메커니즘·날짜 파라미터 거의 동일.
  컬럼 깔끔한 원유 3종으로 인프라 검증 후 제품가로 확장.
- ⚠️ 캐비엇: 비공식 내부 요청 → 예고 없이 바뀔/막힐 수 있음(SLA 없음). robots/약관 확인.
  단일 장애점이라 §3의 FRED 폴백으로 위험 분산.

### 2️⃣ 한국은행 ECOS — 환율 전용  ⭐ 가입대상
- **환율**: 원-달러 + 주요국 환율(여러 분석에 재사용 목적). 일별 확실.
- (두바이유 부담은 오피넷으로 이관 → ECOS의 "두바이 일/월 주기" 불확실성 제거됨.)
- 키 발급: https://ecos.bok.or.kr/api/ → 회원가입 → 인증키 신청 (즉시~1일)

### 3️⃣ FRED (미 세인트루이스 연준) — 교차검증·폴백  ⭐ 가입대상(가볍게)
- 시리즈: `DCOILWTICO` (WTI), `DCOILBRENTEU` (Brent). 일별, 1987년~, 무료, 출처 미 EIA.
- 역할: 오피넷 크롤링이 깨져도 WTI/Brent 2종은 살아있게 하는 **폴백** +
  "크롤링 WTI ≈ FRED WTI" **데이터 품질 교차검증** 베이스라인.
- 키는 지금 받아두되(5분), 수집 코드 빌드는 코어 안정화 후 천천히.
- 키 발급: https://fredaccount.stlouisfed.org/apikeys (계정 가입 후 즉시)

### 4️⃣ OPINET 석유제품 (MOPS) — 보조 (1️⃣ 크롤러 확장)
- 위치: 국제유가 > **석유제품** (`glopopdSelect.do`)
- 내용: 휘발유(95/92RON)·등유·경유(0.001/0.05%)·고유황중유·나프타, 일별 $/Bbl.
- 1️⃣에서 만든 크롤러를 엔드포인트만 바꿔 확장. 정제마진(§4) 분석용.

---

## 4. 왜 싱가포르 제품가를 탐내는가 (정제마진)

- 국내 정유사 공급가는 **원유가가 아니라 싱가포르 국제제품가(MOPS)**에 직접 연동.
- 원유 → 제품 사이에 **정제마진(crack spread)**이 끼어, 원유만으론 설명력이 샌다.
- 비유: 밀(원유)보다 **밀가루(제품가)**가 빵(국내 유가)에 더 가깝다.
- 원유 3종으로 1차 모델을 세운 뒤, 설명력 부족분을 이 제품가로 메우는 순서.

## 5. 미래 확장 후보

- **KOSIS 공유서비스 API** (국가데이터처/통계청) — https://kosis.kr/openapi/
  - 공식 API, 키 1개로 전체. JSON/XML/SDMX.
  - 단, 가격 통계는 대부분 **월별(월평균)** → 일별 시세용 아님.
  - 용도: 나중에 붙일 **월별 거시변수**(물가·금리·산업생산·경기지표 등)의 본진.
- **유류세 / 정책 이벤트** — 국내 유가의 ~45%가 세금. 유류세 한시 인하(2021.11~2024) 등은
  시계열 변수가 아니라 **시행일 더미/단계 변수**로 모델에 반영(수기 캘린더 관리).
- **시차(lag)** — 국제유가 → 국내 반영 2~3주. 데이터가 아니라 모델링 포인트
  (롤링/시차 상관으로 처리. cosine/pearson/spearman 학습이 여기서 쓰임).

## 6. 검토 중 폐기·확정된 사실

- ❌ 오피넷 무료 **API**에 국제유가/제품가 없음 (카탈로그 22종 전부 국내).
  하지만 **화면+CSV로는 제공** (`glopcoilSelect.do` 원유 / `glopopdSelect.do` 제품).
- ❌ FRED·yfinance에 **두바이유 전용 시리즈 없음** (WTI/Brent만).
- ❌ KOSIS는 공식 API 있으나 유가 **일별 아님(월별)**. → 일별 코어 피드로는 부적합.
- ✅ **두바이유 일별의 정답 = OPINET 원유 화면(2008~, CSV).** ECOS 우회/Brent 근사 불필요해짐.
- ✅ 원유 크롤러와 싱가포르 제품가 크롤러는 형제 엔드포인트 → 한 번 만들어 재사용.
